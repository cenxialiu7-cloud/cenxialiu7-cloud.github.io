macOS 安裝步驟

  1. 雙擊下載好的 .pkg 檔案。
  2. 若跳出「無法打開，因為來自未識別的開發者」，按「好」關閉。
  3. 打開「系統設定」→「隱私權與安全性」。
  4. 捲到最下方「安全性」區 → 點 MediaGrab 旁的「強制打開」。
  5. 再次確認「打開」→ 輸入開機密碼，安裝精靈就會開始。

看到「damaged 已損毀」是 macOS 的隔離標記，照上述步驟即可，並非真的損毀。

Windows 安裝步驟

  1. 雙擊下載好的 .exe 安裝程式。
  2. 若出現藍色「Windows 已保護您的電腦」，點左下「其他資訊」。
  3. 展開後點「仍要執行」。
  4. 跟著安裝精靈完成 → 桌面／開始功能表會出現 MediaGrab。

警告是因為程式未付費簽章，並非病毒。所有原始碼公開於 GitHub。

如何使用 · HOW TO

四步開始

  1. 下載安裝：點上方按鈕下載適合你系統的版本並安裝。
  2. 啟動程式：開啟 MediaGrab，瀏覽器會自動打開操作介面。
  3. 貼上網址：在「智能」分頁貼上影音網址，按「解析」。
  4. 開始下載：選擇畫質或集數，檔案會存到「下載」資料夾。

常見問題 · FAQ

你可能想問

MediaGrab 是免費的嗎？

是的，完全免費，所有功能都解鎖，沒有付費版。我們透過選用性的廣告與 Ko-fi 贊助支應開發成本，你也可以在設定裡關閉廣告。

安裝時出現安全警告怎麼辦？

因為程式未經 Apple/Microsoft 付費簽章，系統會顯示警告。Mac 請到「系統設定 → 隱私權與安全性 → 仍要打開」；Windows 請點「其他資訊 → 仍要執行」。詳見上方安裝說明。

支援哪些網站？

支援數千個網站，包含 YouTube、Facebook、Instagram、抖音/TikTok、Twitter、Bilibili、Twitch 等。底層使用開源的 yt-dlp 引擎。

下載的內容合法嗎？

MediaGrab 是個人備份工具。請僅用於下載你擁有版權、Creative Commons 授權、或你有權保存的公開內容。使用者需自行遵守來源網站服務條款與當地著作權法。

會收集我的資料嗎？

MediaGrab 本身不收集、不上傳你的下載紀錄或任何個人資料。本下載頁面載入第三方廣告時可能放置 cookie，詳見隱私政策。
