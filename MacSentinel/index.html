🍎 安裝步驟（90 秒搞定）

  1. 雙擊下載的 MacSentinel-x.x.x.dmg 檔案掛載。
  2. 把 MacSentinel.app 拖曳到 Applications 資料夾。
  3. 從「啟動台」或「應用程式」資料夾打開 MacSentinel。
  4. 首次啟動時 macOS 不會跳出警告——因為已通過 Apple 公證。

💡 通過 Apple 公證 (Notarized) 表示 Apple 已掃描並驗證這個版本沒有惡意程式碼。 Gatekeeper 不會阻擋安裝。

常見問題

MacSentinel 是免費的嗎？會把資料上傳到雲端嗎？

完全免費、開放原始碼、所有掃描與分析都在你電腦本機進行，不會傳送任何資料到任何伺服器。

為什麼需要 Privileged Helper？安不安全？

清理 /Library/LaunchAgents/ 等系統路徑需要 root 權限。Helper 是獨立 XPC daemon、透過 Apple 官方的 SMAppService 註冊，並完整原始碼開放可審。主 App 本身不持有 root。

Apple 公證 (Notarized) 是什麼意思？

表示 Apple 的伺服器已掃描整個 App、確認沒有惡意程式碼與已知漏洞，並用開發者的 Apple Developer ID 簽署。Gatekeeper 因此放行，不會跳警告。如果想驗證簽章來源，可以下載後執行：codesign -dvv /Applications/MacSentinel.app。

MCP 工具要怎麼搭配 Claude Code / Cursor？

安裝後，App 的設定頁有「AI 助理整合 → 顯示連線設定指引」，會教你如何在 Claude Desktop 或 Cursor 的 config 加入一段 JSON，把 macsentinel-mcp binary 註冊成 MCP server。完成後 AI 助理就能呼叫所有 17 個工具。

支援 macOS 13 (Ventura) 或更舊版本嗎？

目前最低要求 macOS 14 Sonoma，因為使用了 SMAppService、Swift Charts、@Observable 等較新 API。短期內不打算往下回溯。

會自動更新嗎？

是的。內建 Sparkle 自動更新框架，每天會檢查一次 GitHub 上的 appcast feed，發現新版本會跳出對話框讓你選擇升級。所有更新都經過 Ed25519 簽名與 Apple 公證雙重驗證。
